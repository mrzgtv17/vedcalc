# Дорожная карта

Список улучшений «Калькулятора ВЭД». Когда пункт внедрён, отметьте его `[x]` и допишите
версию и ссылку на PR, например: `— сделано в 0.6.0 (#9)`. Пункт, сделанный частично,
остаётся `[ ]` с пометкой, что уже есть и чего не хватает.

Объём: **малый** — до одного PR; **средний** — этап вроде модуля «Контейнер»;
**большой** — несколько этапов.

## Больше всего пользы

- [ ] **1. Подстановка ставок по коду ТН ВЭД** — большой. *Частично — 0.6.0 (#10):
  пошлина (в т.ч. специфическая и комбинированная) по коду из бесплатной выгрузки tws.by,
  подбор кода по названию. Не хватает: НДС, акцизов и нетарифных мер — в бесплатном
  источнике их нет (см. п. 17 для НДС).*
  Код или подбор по названию → пошлина, НДС, акциз из локальной базы ЕТТ ЕАЭС с датой
  актуальности (позже — API). Предупреждения о нетарифных мерах: сертификация, маркировка
  «Честный знак». Сюда же — специфические и комбинированные пошлины (EUR/кг), они уже
  заложены в модель. Заготовка: `vedcalc/providers/tnved.py` (`TnvedRateProvider`).
- [x] **2. Связать «Контейнер» с «Импортом»** — средний — сделано в 0.11.0 (#16).
  Позиции импорта с габаритами и весом → модуль укладки → число контейнеров, без ручного
  переноса. *Фрахт «ставка × N контейнеров» не делаем (решение от 28.10.2026): доставка
  до границы уже вводится расходом «Доставка до границы ЕАЭС» — иначе расход задвоится.*
- [x] **3. «Что если»: чувствительность к курсу, пошлине и фрахту** — средний — сделано в 0.9.0 (#15).
  Таблица или график: себестоимость единицы и прибыль при курсе ±5–15 %, фрахте ±20 %,
  другой ставке пошлины. Главный риск импорта — курс на дату оплаты неизвестен.
- [x] **4. Пакетный расчёт для WB** — средний — сделано в 0.12.0 (#17).
  Загрузка XLSX/CSV со списком товаров (габариты, себестоимость, цена, комиссия) →
  таблица прибыли и маржи по каждому, подсветка убыточных, выгрузка в Excel.
- [x] **5. Сохранение всех вкладок в один файл проекта** — малый — сделано в 0.8.0 (#12).
  «Контейнер» и «WB» сейчас не сохраняются. Единый файл, список последних файлов,
  автосохранение и восстановление после сбоя.
